
# 🐍 Curso de Python - Curso em Vídeo
Este repositório contém minhas anotações pessoais, códigos de exemplo e a resolução dos desafios propostos durante o curso de **Python 3** do canal Curso em Vídeo, ministrado pelo professor Gustavo Guanabara.
## 🚀 Status do Projeto
Atualmente, estou focado em resolver e organizar todos os exercícios dos mundos 1, 2 e 3.
> [!IMPORTANT]
> **Nota sobre os exercícios:** Os códigos postados refletem meu aprendizado imediato. Muitos deles ainda passarão por processos de **refatoração e melhoria** para aplicar técnicas mais avançadas e limpas à medida que eu progredir no curso.
> 
## 📚 Estrutura do Repositório
O conteúdo está organizado por módulos (Mundos) para facilitar a navegação:
 * **Mundo 1:** Fundamentos (Tratamento de dados, operadores aritméticos, módulos e estruturas de controle básicas).
 * **Mundo 2:** Estruturas de Controle (Condições aninhadas e estruturas de repetição for e while).
 * **Mundo 3:** Estruturas Compostas (Tuplas, listas, dicionários, funções, módulos e pacotes).
## 🛠️ Tecnologias Utilizadas
 * **Linguagem:** Python 3.x
 * **Ambiente:** VS Code / PyCharm
 * **Ferramenta de Estudo:** Playlist do Curso no YouTube
## 📋 Como Executar os Exercícios
Se você quiser testar algum script localmente:
 1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/Curso-De-PYTHON-Curso-em-video.git
   
   ```
 2. Acesse a pasta do exercício desejado.
 3. Execute com o Python:
   ```bash
   python nome_do_exercicio.py
   
   ```
